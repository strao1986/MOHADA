Multi-Omics integration framework for High-abundance Allergen Discovery in Abalone (MOHADA)

MOHADA is an integrated analytical workflow that combines transcriptome assembly, genome annotation, alignment of allergen databases, and post-alignment analysis. this workflow was developed to explore the comprehensive allergen repertoire for Haliotis discus hannai, as well as other non-modeled species.
